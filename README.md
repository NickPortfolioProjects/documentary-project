# 🎥 Documentary Project - Cine

A curated collection of outstanding documentary films, organised by genre, year, and platform — live at:
**https://nickportfolioprojects.github.io/documentary-project/**

---

## 📖 About

This project is a personal archive and showcase of powerful, thought-provoking documentaries spanning technology, environment, human rights, nature, history, and more. Built as a portfolio piece, it serves as both a resource for discovering essential non-fiction storytelling and a demonstration of clean, accessible web design.

The collection currently features **28 titles** — from award-winning classics to recent releases — grouped by category so you can easily find films that matter to you.
